# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository:

1. Go to the **Security** tab of the repository.
2. Select **Report a vulnerability**.
3. Describe the issue, affected versions, and steps to reproduce.

You should receive an initial response within 5 business days. Do not disclose
the issue publicly until we have had a chance to investigate and, if needed,
publish a fix.

## Disclosure

Once a fix is ready, we will:
1. Publish a patched release.
2. Add a GHSA advisory describing the issue and fixed versions.
3. Credit the reporter, unless they ask to remain anonymous.
